📋 Step 1 — Create Supabase Project

1

Go to supabase.com

Visit supabase.com → Sign up free (GitHub or email).

2

Create New Project

Click New Project → Name: bizsuite → Set a database password → Region: Singapore → Create project. Wait 1-2 minutes.

3

Run the SQL Schema

Go to SQL Editor → New query → Copy & paste the entire contents of supabase_schema.sql → Click Run.

✅ You should see "Success. No rows returned." for each statement.
4

Disable Email Confirmation (optional)

Go to Authentication → Providers → Email → Turn OFF Confirm email → Save. This makes testing easier.

👑 Step 2 — Create Your Super Admin Account

1

Create your auth account

Go to Supabase → Authentication → Users → click "Add user" or "Invite user" → enter YOUR email and password.

2

Register as Super Admin in database

Go to SQL Editor → New query → paste this (replace with YOUR email):

-- Replace 'youremail@gmail.com' with your actual email INSERT INTO super_admins (id, email) SELECT id, email FROM auth.users WHERE email = 'youremail@gmail.com';
✅ This makes your account the super admin. Only super admins can log into admin.html.

🔑 Step 3 — Copy Your API Keys

1

Go to Settings → API

Click ⚙️ Settings (bottom-left) → API.

2

Copy these two values

Project URL: https://xxxxxxxxxx.supabase.co
anon / public key: eyJhbGciOiJIUzI1NiIs…

⚠️ Use ONLY the anon/public key in both files. Never use service_role key in HTML files.

⚡ Step 4 — Connect Files to Supabase

1

Open admin.html → Configure Supabase

Open admin.html in your browser → click "Configure Supabase" → paste your URL and anon key → Save. You'll see "Supabase connected!"

2

Log into admin.html

Enter the email and password you created in Step 2. You're now inside the admin panel!

3

Open app.html → Configure Supabase

Open app.html → click "Configure Supabase connection" (bottom of login screen) → paste same URL and anon key → Save.

✅ Both files are now connected to your cloud database.

🌐 Step 5 — Deploy to the Internet (Netlify — Free)

1

Go to netlify.com

Sign up free → Click "Add new site" → "Deploy manually".

2

Drag & drop your folder

Drag the entire bizsuite/ folder onto the deploy area. Netlify gives you a URL like amazing-dolphin-123.netlify.app.

3

Your URLs are now live:

📊 Client App: yoursite.netlify.app/app.html
🔴 Admin Panel: yoursite.netlify.app/admin.html

💡 You can buy a custom domain (e.g. bizsuite.pk) and connect it to Netlify for just Rs 3,000/year. Looks much more professional to clients.
4

Re-configure Supabase on hosted version

When you open the live URL, click "Configure Supabase" again and paste your keys — the hosted version needs to be configured once too. The keys save in browser localStorage on that device.

🏢 Step 6 — Adding Your First Client

1

Log into admin.html

Go to admin.html → sign in with your super admin email.

2

Click "➕ Add Client"

Fill in: Company name, email, temporary password, plan, status. Toggle on any premium modules they've paid for.

3

Send login details to client

Share with your client:
• URL: yoursite.netlify.app/app.html
• Email: their login email
• Password: what you set
• First time: configure Supabase using your URL + anon key

💡 You can pre-configure Supabase in the HTML file itself so clients don't need to enter it. Ask me to do this when you're ready to ship to clients.
✓

Done! Client is live

Client logs in, sees their own empty dashboard, starts adding sales, expenses, products. Their data is 100% isolated from all other clients.

❓ Common Questions

Can client A see client B's data?

Absolutely not. Row Level Security in Supabase ensures each client can only ever see their own data, even if they somehow guessed another client's ID.

What if I want to rename the product?

Just tell me your product name and I'll update both files. All branding is in one place — easy swap.

Can I add new modules later?

Yes. You can ask me to build any new module (HR, fleet, manufacturing, etc.) and I'll add it to the feature flag system. Existing clients don't see it until you enable it for them.

How many clients can I have on Supabase free tier?

Up to ~50 clients comfortably on the free tier (500MB database). When you grow past that, upgrade to Supabase Pro for $25/month — a tiny cost compared to your revenue.

One client needs a completely custom feature. What do I do?

Charge them a one-time custom development fee, ask me to build it, and add it as a feature flag that only they have enabled. Their custom feature stays invisible to all other clients.
